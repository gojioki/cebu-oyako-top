# セクション別編集方式

プロジェクト全体の恒久ルールは、ルートの `AGENTS.md` を正とします。

今後は、13MB前後の統合HTMLを修正のたびに読み書きしません。

## FVを修正するとき

主に次の2ファイルだけを編集します。

- `sections/01_fv_trust_mother.html`
- `css/site.css` のFV関連部分

確認には `preview/ver03_FV専用プレビュー.html` を使います。

このFV区切りには以下を含めています。

1. カスタムヘッダー（プレビュー時の見え方確認用）
2. FV
3. 信頼4カード
4. 「母子留学を検討中の方にも。」メッセージ

SWELLへ入れる際は、ヘッダーとFVブロックを分けて扱えます。

## 全体を確認するとき

`preview/ver03_全体軽量プレビュー.html` を使います。画像はローカルファイルを参照するため軽量です。

## 外へ持ち出すとき

ビルド後の `downloads/ver03_ぶっ飛びセブ島親子留学_TOP_PC_統合版.html` を使います。このファイルだけはCSSと画像をすべて内部に埋め込んでいます。

## ファイル名ルール

- 最新ファイルは必ず先頭を `ver番号_` にする。
- 現在のバージョンは `VERSION.txt` で管理する。
- 次の確定版へ進むときは `ver03` を `ver04` のように更新する。
- 日付やプロジェクト名よりも、バージョン番号を必ず先に置く。

## 汎用テンプレート化の順序

1. まずPC版の見た目を基準PNGに合わせて確定する。
2. 確定後に、色・フォント・角丸・影・主要余白を `:root` の `--btv3-*` 変数へ集約する。
3. CSSをブロック別ファイルへ分割し、各sectionのスマホ指定も同じファイルへ移す。
4. 各sectionが単体コピーで成立することを確認する。
5. 最後に統合版を生成し、SWELL用ブロックとして書き出す。

現行CSSは、接頭辞については `btv3-` へ統一済みです。一方、デザイン値の完全変数化とブロック別CSSへの分割は、見た目の確定後に行います。
