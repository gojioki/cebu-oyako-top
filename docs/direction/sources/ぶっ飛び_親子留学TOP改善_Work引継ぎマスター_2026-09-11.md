# ぶっ飛び｜親子留学TOP改善 Work引継ぎマスター

更新日：2026年9月11日

## 1. 目的と現在地

最終目的は、cebu-oyako.com のトップページにあるリンクを上から順に対応記事で埋め、各導線を完成させること。これとは別に、トップページの料金表を調整する。

直近の優先順位は「リンク進捗台帳を確定 → #2を完成 → #3費用完全ガイドとTOP料金表を同時に整える」。#2は完成済み。#3と料金表は改訂案まで完成し、本人確認待ち。WordPressおよび公開中のTOPページには未反映。

## 2. 料金部分の確定方針

|項目|確定内容|
|---|---|
|TOPの家族条件|親1人＋子ども1人の2人に固定|
|TOPの受講条件|親子とも英語レッスンを受講|
|TOPの代表値|1週間 約50万円／2週間 約60万円／4週間 約90万円|
|記事の安全幅|1週間 50〜65万円／2週間 60〜80万円／3週間 70〜95万円／4週間 85〜110万円|
|4週間約90万円の内訳|学校・宿泊55万円／航空券・保険20万円／現地支払い・生活費15万円|
|価格差への備え|TOPは丸めた代表値、記事はレンジ・前提条件・基準日を明記|

TOPに家族3〜4人の見積りを混ぜない。親が付き添いのみ、家族3〜4人、一部だけ受講、ジュニアキャンプは条件差が大きいため、詳細記事側で別パターンとして説明する。

## 3. 記事で伝えるパラダイム

親子留学は単純な「1人分×人数」では計算できない。費用と選択肢は、渡航人数・受講人数・必要な部屋・渡航時期で変わる。

学校の選びやすさは、概ね「親1人＋子1人・2人とも受講 ＞ 親1人＋子1人・子どもだけ受講 ＞＞ 親子3人以上・一部だけ受講」。人数と受講者がずれるほど、非受講者の滞在、部屋定員、食事、送迎、外部宿泊などを同時に確認する必要がある。

## 6. 公開に関する制約

- 本人の明示的な指示なしにWordPressへ投稿しない。
- Sitesの改訂版も、確認前に公開版へ反映しない。
- 公開直前に為替、対象校の料金、含有項目、リンク先URLを再確認する。
- `href="#"`、相対画像パス、仮画像、未確定CTAは公開前に置換する。

## 7. 次に再開するときの順番

1. TOP料金表プレビューと#3記事プレビューを本人がまとめて確認する。
2. 指摘をTOPの動作版と記事原稿の両方へ反映し、数字・表現を同期する。
3. 授業日数の暫定部分と公開直前の学校料金を最終照合する。
4. 承認後にTOP料金表と#3記事を本番へ反映し、進捗台帳を「公開済み」へ更新する。

新しいWorkで再開する場合は、このファイルと進捗台帳を最初に読み、「#3費用完全ガイドとTOP料金表の確認待ちから再開」と指示すればよい。
