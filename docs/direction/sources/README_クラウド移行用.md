## クラウド側での再開位置

「#3費用完全ガイド」と「TOP料金表」の運営者レビューから再開します。この2つは料金条件と数字が連動するため、セットで確認します。

確定している料金条件：

- 親1人＋子ども1人
- 親子とも英語レッスンを受講
- TOP代表値：1週間約50万円／2週間約60万円／4週間約90万円
- 記事の安全幅：1週間50〜65万円／2週間60〜80万円／3週間70〜95万円／4週間85〜110万円
- 4週間の内訳：学校・宿泊55万円／航空券・保険20万円／現地支払い・生活費15万円

## 公開前の注意

- 運営者の明示的な承認なしに公開しない
- TOP料金表の `href="#"` を正式な記事URLへ置き換える
- 記事プレビューの重複H1を1つに整理する
- 「編集・参照情報」「公開前の編集メモ」は公開本文から除外するか、読者向け注記へ変換する
- 3回目の授業日数・レッスン数を一次資料で照合する
- 公開直前に為替、学校料金、含有項目、SSP・ビザ、祝日授業、キャンセル条件を再確認する
