# 共通ヘッダー・フッター・記事サイドバー方針

基準日：2026-09-18
状態：初期方針承認済み・デザイン未確定

## 基本方針

- トップページは現在の1カラム構成を維持する。
- 通常記事はPCで本文＋右サイドバーの2カラムを基本とする。
- サイドバーは凝った装飾より、ゲームWikiのような短く明確な案内性を優先する。
- 共通部分は本番に直接入れず、ローカルで設計後、ステージングで検証する。

## 右サイドバーの初期構成

1. このサイトで分かること
2. 目的から探す
   - 費用
   - 学校選び
   - 準備
   - 年齢
   - 期間
   - 体験談
3. 出発までの流れ
4. この記事に関連するページ

## 初期段階で入れないもの

- タグクラウド
- 人気記事ランキング
- 広告枠
- リンク先が未完成のメニュー

30記事程度が揃った後、利用状況を見て追加を判断する。

## 実装順

1. SWELL標準を土台に共通ヘッダーを整理
2. 簡潔な共通フッターを作成
3. 費用完全ガイドを試験記事として右サイドバーを実装
4. PC・タブレット・スマホで検証
5. 承認後に他の記事へ展開
