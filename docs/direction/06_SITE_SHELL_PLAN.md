# 共通ヘッダー・フッター・記事サイドバー方針

基準日：2026-09-19
状態：共通ヘッダー・フッターをステージングへ反映済み。右サイドバーは設計済み・未実装

## 基本方針

- トップページは現在の1カラム構成を維持する。
- 通常記事はPCで本文＋右サイドバーの2カラムを基本とする。
- サイドバーは凝った装飾より、ゲームWikiのような短く明確な案内性を優先する。
- 共通部分は本番に直接入れず、ローカルで設計後、ステージングで検証する。

## 共通ヘッダーの確定方針

- SWELL標準ヘッダーを土台とし、独自ヘッダーは追加しない。
- サイト名は青ではなく、黒に近い濃紺 `#243142`を使う。
- `β版`のブルーをアクセントとして残す。
- PCは現行の横メニュー構成を維持する。
- タブレット・スマホは、ハンバーガーと検索を残し、下段の横並びメニューを非表示にする。
- メニュー表示は「親子留学」「セブ島留学」「費用・準備」「体験談」「学校一覧」とする。
- ヘッダー内に縦区切りやCTAを追加しない。
- 最小文字サイズは11pxを下回らない。

確認用プレビュー：`modular/preview/common-header-20260918-preview.html`

## 共通フッターの確定方針

- 濃紺のグラデーション背景とし、サイト名・運営者・サイト説明を左側へ置く。
- 右側のサイトガイドは「親子留学」「学校選び」「費用」「3回の体験」の4項目とする。
- 4項目はTOP内の既存アンカーへ接続し、未公開記事へ直接リンクしない。
- タブレットでは1カラム、スマホではナビを縦積みにする。
- SWELL標準フッターはCSSで非表示とし、二重表示を防ぐ。
- ステージングの「フッター直前」ウィジェットへ配置し、PC・タブレット・スマホで確認済み。
- 本番サイトへは未反映。記事テンプレート検証後に反映時期を判断する。

正本HTML：`modular/sections/12_footer.html`
確認用プレビュー：`modular/preview/common-footer-20260918-preview.html`
SWELL追記CSS控え：`docs/direction/snippets/SWELL_COMMON_FOOTER.css`

## 右サイドバーの初期構成

1. このサイトで分かること
2. 目的から探す
   - 費用
   - 学校選び
   - 準備
   - 年齢
   - 期間
   - 体験談
3. 出発までの流れ
4. この記事に関連するページ

## 初期段階で入れないもの

- タグクラウド
- 人気記事ランキング
- 広告枠
- リンク先が未完成のメニュー

30記事程度が揃った後、利用状況を見て追加を判断する。

## 実装順と現在地

1. SWELL標準を土台に共通ヘッダーを整理（ステージング完了）
2. 簡潔な共通フッターを作成（ステージング完了）
3. 費用完全ガイドを試験記事として右サイドバーを実装（次の作業）
4. PC・タブレット・スマホで検証
5. 承認後に他の記事へ展開

## ステージング側の保守メモ

- 「追加CSS」には、以前のTOP専用ヘッダー調整も残っている。現在の共通ヘッダーCSSが後段で上書きしており、表示上の競合は確認されていない。
- 旧ブロックだけを画面上で部分削除すると誤消去のリスクがあるため、現時点では温存する。次回のCSS整理時に追加CSS全体を退避してから統合する。
- 本番へ移す際は、`docs/direction/snippets/` の確定控えを使用し、ステージングの追加CSS全体をそのまま複製しない。
