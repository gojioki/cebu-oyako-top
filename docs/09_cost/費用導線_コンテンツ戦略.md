# 費用ブロックからのコンテンツ戦略

## 1. トップの費用ブロックの役割

トップだけで費用の詳細を説明しきらない。読者に「うちでも現実的かも」と思ってもらい、自分の条件に近い比較ページへ送る。

| トップでやること | トップでやらないこと |
|---|---|
| 親子留学かジュニアキャンプかを分ける | 学校ごとの詳細料金説明 |
| 主要条件から総額目安を見せる | 16パターンすべての長文解説 |
| 通常期と繁忙期の差を見せる | 費用ブロック単体でのSEO順位狙い |
| 比較ページへ送る | 各学校への直接送客 |
| 斎藤家の実費で信頼を補強する | 単身留学向けの費用目安 |

## 2. 全体ツリー

```text
トップページ
└─ 費用ブロック
   ├─ 親子で行く
   │  ├─ 期間：1〜4週間
   │  ├─ 親の授業：受ける／受けない
   │  ├─ 宿泊：学校内・提携／外部自己手配
   │  └─ 親子留学プラン比較ページ
   │     ├─ 条件に対応する学校一覧
   │     ├─ 学校ごとのプラン比較
   │     ├─ 学校詳細ページ
   │     └─ 条件別の解説記事
   ├─ ジュニアキャンプ
   │  └─ 募集中のジュニアキャンプ比較ページ
   │     ├─ 夏休みキャンプ
   │     ├─ 春休みキャンプ
   │     ├─ キャンプ詳細ページ
   │     └─ WEG・引率・安全管理の解説記事
   └─ 斎藤家の実費
      ├─ GW・16日間
      ├─ 夏・30日間
      └─ 年末年始・31日間
```

## 3. 枝分かれを増やしすぎない原則

16の条件ごとに16ページを作らない。親子留学は一つの「プラン比較ページ」で受け、トップで選んだ条件を初期フィルターとして引き継ぐ。

```text
/?weeks=2&parent_lesson=no&stay=outside
```

記事を分けるのは、条件の組み合わせではなく、読者の疑問や検索意図が明確に異なる場合に限る。

## 4. 必要な主要ページ

| 優先度 | ページ | 役割 |
|---|---|---|
| 1 | 親子留学プラン比較 | トップの3条件を引き継ぎ、対応校を比較 |
| 1 | ジュニアキャンプ比較 | 募集中の日程・対象年齢・総額・引率を比較 |
| 1 | 費用完全ガイド | 航空券・授業・宿泊・現地支払いの内訳を解説 |
| 2 | 期間別費用ガイド | 1週間・2週間・1か月の選び方と総額を解説 |
| 2 | 親は授業を受けない親子留学 | 対応校・費用・注意点を解説 |
| 2 | 外部ホテル・コンドから通う親子留学 | 外泊可否・送迎・食事・生活管理を解説 |
| 2 | 斎藤家の実費記事 | 請求書ベースの実費で信頼を補強 |
| 3 | WEG・ジュニアキャンプ準備 | 保護者が不安になる手続き・安全面を解説 |

## 5. 親子留学比較ページの構成

| 項目 | 内容 |
|---|---|
| 選択条件 | 期間・親の授業・宿泊方法 |
| 結果 | 条件に対応する学校のみ表示 |
| 学校カード | 学校名・対象年齢・期間・親の受講可否・外泊可否・総額 |
| 料金 | 同じ家族構成・期間・為替条件で統一 |
| 注意点 | 部屋・食事・送迎・SSP・教材・保険・航空券の範囲 |
| 次の行動 | 学校詳細、費用内訳、問い合わせへ進む |

## 6. ジュニアキャンプ比較ページの構成

| 項目 | 内容 |
|---|---|
| 募集情報 | 実施季節・日本出発日・帰国日・募集状況 |
| 対象 | 年齢・学年・英語レベル・最少催行人数 |
| 総額 | 授業・滞在・食事・航空券・引率・アクティビティの含有範囲 |
| 安全管理 | 日本人引率・現地サポート・病気やトラブル時の対応 |
| 手続き | WEG申請・保険・パスポート・同意書 |

## 7. 学校調査で保持するデータ

| 分類 | 保持する項目 |
|---|---|
| 基本 | 学校名・エリア・対象年齢・最短期間 |
| 授業 | 子どもの授業時間・親の受講必須／任意／不要 |
| 宿泊 | 学校寮・提携ホテル・外泊可否・通学条件 |
| 料金 | 1〜4週間の授業料・宿泊費・食費・現地支払い・繁忙期加算 |
| 追加費用 | 航空券・保険・SSP・教材・送迎・水道光熱費 |
| 出典 | 公式URL・確認日・為替レート・問い合わせ回答 |

## 8. CTAの対応表

| トップの箇所 | 飛び先 |
|---|---|
| 親子留学の主CTA | 選択条件を引き継いた親子留学プラン比較 |
| 「費用の詳しい内訳」 | 費用完全ガイド |
| ジュニアキャンプCTA | 募集中のジュニアキャンプ比較 |
| 斎藤家の実費 | 請求書ベースの費用記事 |

## 9. 作成順序

1. トップに費用ブロックv4を仮実装
2. 学校・キャンプの料金データを収集
3. 親子留学プラン比較ページを作成
4. ジュニアキャンプ比較ページを作成
5. トップの仮金額とCTAを差し替え
6. 費用ガイド・条件別記事を順次追加
7. クリック率を見ながら記事と導線を改善

## 10. 成功指標

| 指標 | 確認すること |
|---|---|
| 条件選択率 | 費用ブロックが実際に操作されているか |
| 主CTAクリック率 | 学校比較への興味を生み出せているか |
| 費用記事への回遊 | 詳細な不安解消につながっているか |
| 学校詳細への回遊 | 費用確認から学校検討へ進んでいるか |
